Uninformative noise (objects crossed by X-rays at a similar intensity to more relevant objects, owing to similar material density) was artificially removed from those renders using clip boxes, edge contrast, and a noise-reduction operation. ROIs were always blended with the original volumetric datasets to obtain a smoother surface, which attenuated the ROIs’ often rugose and pixelated texture. Renders of individual postcranial skeletal elements with a realistic bone-like texture were obtained by masking out all elements located outside the bounds of the ROI of the desired element in copies of the original µCT-scanned datasets. A more detailed protocol for ROI masking is available in another votive mummy description (Warner et al., in prep.).

The fractal dimension of the nasal turbinates in each cat skeleton was measured to quantify interspecific variation in the genus *Felis*, and thus to identify the species of the mummified cat. To ensure anatomical consistency across all specimens, all four CT reconstructions encompassing the cats’ heads were re-oriented along the same three rotational axes in 3D space. To establish roll alignment, the two lowest points of the mandibles were aligned (Southerden et al., 2018). Pitch was aligned parallel to the palatal plate with a 25 mm ruler positioned along the anterior palate, and the dataset was rotated until this reference axis lay parallel to the x-axis in 2D view (Weiss et al., 2004). Yaw was aligned relative to the internarial septum, relying on midline symmetry (Díaz Martínez et al., 2024).

The segmentation approach was tailored to address variations in tissue intensity across the sample even though all specimens were scanned at similar resolutions. The mummified cat RM 2728.1 had nasal turbinate bone intensities similar to the surrounding skull bone. In contrast, the turbinates of the three modern cats had intensities more similar to the image background, which indicated that they were structurally less dense. Consequently, the mummified cat’s nasal turbinates were segmented using the same custom neural network previously trained on the entire skull, in conjunction with a 3D object mask which isolated the nasal cavity from the rest of the skull. No manual segmentations of additional reference slices were required, and surrounding cranial bone volume was manually removed using 2D and 3D ROI tools to isolate the desired ROI. In contrast, a new custom neural network was designed and trained to segment the three modern cats’ nasal turbinates (Table S1). This network was trained primarily on manually segmented reference slices from all three modern datasets along a dorsoventral axis. The African cat RM 7303 yielded the poorest initial segmentation results, so additional training rounds which included reference slices along the rostrocaudal axis were required to improve the network’s predictions. A new multi-ROI was generated for each specimen, from which the turbinate class was extracted as a single ROI and manually corrected. Each turbinate ROI was exported as a stack of 8-bit binary TIFF files, with empty slices removed manually.

The slice analysis was executed with custom automation scripts. An ImageJ macro was written to iteratively loop through the complete stack of TIFF slices for each specimen. For each individual slice, the image was inverted so that the turbinate ROI corresponded to foreground (counted) pixels, and its space-filling properties were quantified by calculating the fractal dimension (*D*) with the Fractal Box Count plugin, using box sizes of 2, 3, 4, 6, 8, 12, 16, 32, and 64 pixels. These sequential *D* measurements, alongside their slice indices, were exported as CSV files for each specimen. A custom Python script was then used for graphical analysis and visualization. To account for inter-individual variation in absolute nasal cavity length, the position of each slice was normalized to a percentage scale (0–100%). A rolling mean filter was applied uniformly across all specimens to smooth the fractal-dimension curves, generating the final plots. The code and data required to reproduce this slice analysis are in this repository (*add Data S number*).
